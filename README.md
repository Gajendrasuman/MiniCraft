# MiniCraft: Showcasing My Mini Projects 🚀

Welcome to **MiniCraft**, a personal portfolio that brings together all my mini projects under one roof. From small experiments to useful utilities, MiniCraft showcases the journey of my learning and creativity. 💻✨

---

## 🛠️ Features

- **Interactive Project Cards:**  
  Hover-enabled cards displaying project details with live demo and GitHub links.  

- **Project Filters:**  
  Filter projects by category (Web, Games, Tools, etc.) or tech stack.  

- **Live Demos:**  
  Explore hosted mini-projects directly from the platform.  

- **Responsive Design:**  
  Optimized for both desktop and mobile devices.  

- **Dark Mode:**  
  Because developers love it! 🖤

## 🧰 Tech Stack

- **Frontend:**  
  [Next.js](https://nextjs.org/) - React-based framework for fast, SEO-friendly UI.  
  [Tailwind CSS](https://tailwindcss.com/) - Modern utility-first CSS framework.  

- **Backend (Optional):**  
  [Node.js](https://nodejs.org/) + [Express.js](https://expressjs.com/) - For dynamic project data.  

- **Database (Optional):**  
  [MongoDB](https://www.mongodb.com/) - To store project details (or JSON for static data).  

- **Hosting:**  
  [Vercel](https://vercel.com/) - Deploy your portfolio with ease.
